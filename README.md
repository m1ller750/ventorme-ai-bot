# Ventorme — бэкенд Telegram-напоминаний

Telegram-бот для сайта Ventorme. Сайт сохраняет в Supabase username, время и часовой пояс пользователя, а бот привязывает его Telegram-чат и каждый день присылает напоминание о серии.

## Стек

- **Python** — бот (`bot.py`)
- **Telegram Bot API** — сообщения и команды
- **Supabase** (Postgres, Row Level Security) — общая база с сайтом

## Команды бота

`/start` — привязка (сайт открывает бота со ссылкой `?start=<token>`) · `/status` — серия и настройки · `/time 20:00` — время напоминания · `/stop` / `/resume` — выключить или включить напоминания.

При старте бот записывает свой `@username` в таблицу `app_config`, и на сайте в «Настройках» появляется кнопка «Открыть бота».

## Код

- `bot.py` — бот: привязка чата, ежедневные напоминания, команды
- `schema.sql` — схема базы: таблицы, RLS, функции `check_in`, `link_child`, `get_children`
- `requirements.txt` — зависимости Python
